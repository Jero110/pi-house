# Changelog

## 0.1.0

First release as pi-house, started from Faro.

- Command `pih` (also `pihouse`); configuration in `~/.pihouse`; agent-link harness `pihouse`.
- Black, white and gray theme with one lilac accent.
- Single-line status bar: folder, branch, provider and model, context window, and the 5h and 7d usage windows of the
  Claude or ChatGPT login in use (tokens and cost when a login has no windows).
- Plain text header (no logo, no slogan) and a black and white logo in `assets/` for the README.

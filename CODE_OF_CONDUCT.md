# Code of Conduct

pi-house is open to everyone who wants to use it or improve it. To keep it that way:

- Be kind and assume good faith. Disagree with the idea, not the person.
- No harassment, discrimination, personal attacks or unwelcome sexual attention, in any language.
- Do not publish other people's private information.
- Keep feedback specific and useful, and accept it the same way.

Maintainers may edit, hide or remove comments, issues and pull requests that break these rules, and may block
repeat offenders. To report a problem, open a private security advisory on this repository (Security tab, "Report a
vulnerability") and say it is a conduct report; only the maintainers can read it.
